Cómo se usa

Sigue los números. No hace falta saber de computadores.

1. Abrir

En la carpeta del proyecto escribe npm start y abre http://127.0.0.1:4173/.

La pastilla verde dice dónde se guardan los datos: en este equipo o en Supabase.

2. Tu nombre

En la primera pantalla escribe el estudio, tu nombre y tu cargo. Pulsa Guardar.

3. Un cliente

  1. Entra a Clientes.
  2. Pulsa Agregar cliente.
  3. Completa nombre, teléfono y correo.
  4. Elige un color y guarda.

El cliente se queda aunque cierres sus casos.

4. Un caso

  1. Entra a Casos y pulsa Nuevo caso.
  2. Pon el nombre y elige el cliente.
  3. Guarda y haz clic en el caso.

Adentro puedes ver el resumen, anotar documentos, fechas, tareas y notas. El asistente solo arma un borrador. Tú lo revisas.

5. Cerrar un caso

Cuando el caso termina, pulsa Cerrar y borrar.

Se eliminan el caso, sus documentos, tareas, notas y fechas. Así no ocupan espacio.

El cliente no se borra.

6. Supabase, una sola vez

  1. Crea un proyecto gratis en supabase.com.
  2. Abre SQL Editor, pega el archivo supabase/schema.sql y pulsa Run.
  3. En Project Settings → API copia la URL del proyecto y la clave service_role.
  4. Esa clave es secreta. No la publiques.
  5. Crea el archivo server/.env con la URL y la clave. Hay un ejemplo en server/.env.example.
  6. Vuelve a escribir npm start y recarga la página.

La pastilla debe decir Guardado en Supabase.
